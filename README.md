# しょぼねこクエスト

PCブラウザで遊べる、2〜4人のオンライン協力アクションです。3つのワールドを仲間と進み、全員でゴールを目指します。1人用の練習モードもあります。

## 遊び方

1. 全員が公開サイトを開きます。
2. ホストが「ルームをつくる」を押し、6文字の合言葉を友達へ伝えます。
3. ほかのプレイヤーは名前と合言葉を入力して参加します。
4. 2〜4人がそろったら、ホストが「みんなで出発！」を押します。

ホストはゲームのタブを開いたままにしてください。ホストが退出・再読み込みするとルームは終了します。

| 操作 | キー |
| --- | --- |
| 移動 | ← → / A D |
| ジャンプ | Space / ↑ / W |
| 近くの仲間を救助 | E 長押し |
| 復帰 | R |

番号のある2つのスイッチに別々の仲間が乗ると扉が開きます。チェックポイントは全員で共有します。

## 通信

WebRTC（PeerJS）を使用します。接続の仲介にPeerServer Cloudを使用し、ゲームの状態は参加者のブラウザ間で通信します。ネットワークやVPNの設定によって接続できないことがあります。その場合は別の回線を試してください。

## 配置

`index.html` は必要な画像、スタイル、ゲームコードを内包した静的ファイルです。GitHub Pagesで main ブランチのルートを公開元に設定すると配信できます。ホスティング用の秘密情報は含みません。

キャラクター・背景・ゲームデザインはこのゲーム用のオリジナルです。
