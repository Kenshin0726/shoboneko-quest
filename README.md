# しょぼねこクエスト — 激ムズ9面

PCブラウザ向けのオンライン協力ジャンプアクション。

**遊ぶ → https://kenshin0726.github.io/shoboneko-quest/**

## 遊び方

1. 全員が同じURLをPCで開く。更新前から開いている人はページを再読み込み。
2. ホストが9面からステージを選び「ルームをつくる」。友達は6文字の合言葉で参加。
3. ホストはロビーでステージを変更可能。1〜5面は2〜4人、6〜9面は4人必須。
4. 全スイッチに別々の仲間が乗り、指定秒数キープして扉を開く。途中で離れたり倒れたりすると計測リセット。
5. 参加者全員がゴールするとクリア。ホストは冒険中でも全員をステージ選択へ戻せる。

ホストはゲームのタブを開いたままにしてください。ホストが閉じたり再読み込みするとルームが終了します。通信環境・VPN・ファイアウォールによって接続できない場合があります。

## 操作

- ← → / A D：移動
- Space / ↑ / W：ジャンプ（長押しで高く）
- E 長押し：近くの仲間を救助
- R：チェックポイントに復帰

倒れると5秒で復帰。途中の旗は全員共通のチェックポイント。星は任意の寄り道チャレンジ。1人練習では協力扉が開き、全9面を自由に練習できます。

## 配信

`index.html` はゲーム本体・画像・スタイルをまとめたファイルです。GitHub Pages の main / (root) で公開。オンライン接続にはPeerJSの公開シグナリングサービスとWebRTCを使用します。
